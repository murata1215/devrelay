## 発見
`apps/web/src/contexts/LanguageContext.tsx:39` に既に `document.documentElement.lang = language` を設定する
`useEffect` が存在していたが、これは React マウント後に走るため、ブラウザの翻訳判定（HTML 読み込み・
パース時点で行われる）には間に合わないことが分かった。静的 HTML の `lang` 属性を正しく宣言することと、
ランタイムでの言語切替時の `lang` 更新は別レイヤーの問題であり、両方が必要（後者は既存実装のまま維持）。

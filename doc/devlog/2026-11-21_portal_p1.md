# ポータル P1: Yahoo 風 3 カラム化・D:\portal の PDF・コミット歴ニュース・自分の TODO（2026-11-21）

会社リポジトリのみ（ポータル自体が会社独自機能。#024 で追加した `/portal` の作り替え）。

## 背景
- 既存の `/portal` はヒーロー＋カードの紹介ページで、毎日開く入口になっていなかった。
- 手書き案（Devrelay Portal: 上にナレッジ検索、左にリンク、中にニュース「最新 / アップデート」、右に課題一覧
  「Backlog の自分のもの・全体課題・自分の TODO」）と Yahoo のトップの雰囲気を目指す。
- 資料は `D:\portal` に置いた PDF をそのまま見せたい。DevRelay の更新はコミット歴をエクスポートし、
  AI で毎日ニュースにしたい（土台の仕掛けとして）。

## ユーザー決定
1. PDF はログイン不要で閲覧可（社内ネットワーク内のみ公開）
2. PDF 以外（docx / xlsx / csv）は対象外。一覧にも出さず配信もしない（`Devin利用規約` は PDF 0 件なので分類ごと出ない）
3. 左リンク: 座席表（freeaddress/seat.php）・端末台帳（PCkanri/TISA_V3）
4. ニュース AI の鍵は `DEVRELAY_ANSWER_API_KEY` / `DEVRELAY_ANSWER_MODEL` を流用（専用鍵は作らない）
5. 一度に全部

## 実装
### 画面（apps/web）
- `pages/PortalPage.tsx` を作り替え: ヘッダー（DevRelay Portal・ログイン）→ ナレッジ検索欄（`/knowledge?q=`、未ログインはログイン経由）
  → 3 カラム（`lg:grid-cols-[220px_1fr_300px]`、スマホは ニュース → 左 → 右 の縦積み）。
  - 左: 使い方（資料の分類 → `/portal/docs?c=`）・方針（DIR 直下 PDF を直接開く）・リンク（portal.json）・DevRelay 各画面
  - 中: ニュース（タブ: 最新 = 全部 / アップデート = `category:update`）。portal.json のお知らせも `notice` として混ぜる。15 件ずつ「もっと見る」
  - 右: 課題一覧（Backlog = 準備中・全体課題 = issues.json・自分の TODO = DB、未ログインは「ログインすると使えます」）
- 新規 `pages/PortalDocsPage.tsx`（`/portal/docs?c=<分類>`）: 分類ごとの PDF カード一覧（更新日・サイズ）。新しいタブで開く。
- `lib/portal-rules.ts` に純関数を追加（`normalizePortalDocs/News/Issues`・`portalDocFileHref`・`portalDocsPagePath`・
  `mergeNoticesIntoNews`・`filterPortalNews`・`buildKnowledgeSearchPath`・`formatPortalFileSize`）。`lib/api.ts` に `portal`。

### サーバー（apps/server）
- `routes/portal-api.ts`
  - `portalPublicRoutes`（ログイン不要）: `GET /api/portal/docs` / `docs/file?path=` / `news` / `issues`
  - `portalTodoRoutes`（ログイン必須・本人のみ）: `GET/POST /api/portal/todos`、`PATCH/DELETE /api/portal/todos/:id`
- `services/portal-rules.ts`（純関数）・`services/portal-service.ts`（fs）
  - PDF の配信は 2 重の防御: 文字列判定 `isSafePortalRelPath`（絶対パス・`..`・`\`・`:`・制御文字・PDF 以外を拒否）
    ＋ realpath が DIR の内側であること。`news/`・先頭 `.`/`_` のフォルダとシンボリックリンクは見ない。
    日本語ファイル名は #019 の `contentDisposition('inline', …)`。
- env: `DEVRELAY_PORTAL`（既定 1、0 で全 404）、`DEVRELAY_PORTAL_DIR`（未設定なら空応答）。この機は `D:\portal`。

### ニュースの仕掛け（エクスポート → 加工）
- CLI `portal:news`（`scripts/portal-news.ts`、`--dry-run` / `--no-ai` / `--days N`）
  1. エクスポート: リポジトリ HEAD の前回位置（`news/state.json` の lastHash）以降のコミットを
     `news/commits/YYYY-MM-DD.jsonl`（実行日 JST）に追記（生データは消さない）。初回・履歴外は直近 14 日。
  2. 加工: docs/test/chore 等を除いたコミットを AI（`gpt-4o-mini`）で社員向けに 1 件へ要約。鍵が無い・失敗・JSON 不正なら
     件名整形（`feat(x):` を外す・最大 6 行＋ほか N 件）に切り替え。
  3. `news/items.json` に id（`update-<日付>-<HEAD短縮>`）重複なしで追記。同じ id の既存行は上書きしない（手直し保護）。
- 毎日: `C:\tools\portal-news.cmd`（ASCII のみ。ログは `D:\portal\news\portal-news.log`）。
  登録: `schtasks /Create /TN "DevRelay Portal News" /TR "C:\tools\portal-news.cmd" /SC DAILY /ST 07:00 /RU SYSTEM /F`
  （HTTPS_PROXY はマシン環境変数なので SYSTEM でも AI に届く）
- 拡張点: メール等の他ソースは同じ items.json に `category: "mail"` 等で書けば「最新」に載る。

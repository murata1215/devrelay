## 実装した4つの仕様逸脱（要判断、プランで事前承認済み）

- **D1（4層防御）**: `allowedTools: []` はツール無効化にならない（SDK 型定義で「プロンプト無しで
  自動許可するツール名」と確認）ため `tools: []` を本命に採用し、`disallowedTools`・`canUseTool`
  無条件 deny・`permissionMode:'plan'` の4層 + `mcpServers:{}`/`strictMcpConfig:true` で防御。
- **D2（専用 WS チャネル）**: `sendPromptToAgent()`/`handleAiPrompt` の再利用は構造的に 180 秒予算を
  超過し（`reconcileForRunner()` 最大3分ブロック等）、`archiveWorkState()`/`loadStorageContext()`/
  `saveConversation`/`clearOutputDir` 等の対話セッション向け副作用も個別ガードが必要になるため、
  `server:raw:prompt`/`agent:raw:result` の専用ペアを新設。既存3関数は0行変更。
- **D3（インメモリ流量制御）**: `seatKey` を DB カラムに追加せず（人手 ALTER 回避）、
  `${userId}:${seatKey}` 名前空間化したインメモリ Map で同時実行1を Node 単一スレッドの
  test-and-set により正確に担保。`Session`/`Message` 行は usage 記録のため新ルートが自前で作成。
- **D4（Windows Electron 対象外）**: `agents/windows/src/services/ai-runner.ts` は
  `@anthropic-ai/claude-agent-sdk` を import しておらず system prompt 完全置換を実装できないため、
  capability 申告から `raw-completion` のみ除外。

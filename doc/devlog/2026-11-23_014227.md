# 2026-11-23 01:42 JST ｜ サイクルSB-0: Sandbox 実行（外向き通信制限）の組み込み調査

## 要求
Windows の Agent で AI ツール（Claude Code / Devin CLI）を「制限された身元」で実行し、許可した
宛先以外へ通信できない状態を DevRelay の機能として提供したい（Windows ファイアウォール + 仮想アカウント
+ 中継プロキシ方式。手動検証は 2026-11-20〜22 に実機 2 台で実施済み、本リポジトリ未収録）。本サイクルは
read-only 調査のみで、既存コードのどこをどう変えれば実現できるかを調べ、段階分けした実装案を Plan として
出す。AskUserQuestion 不使用・調査時点 HEAD `e917b46`。

## 実行
- A〜H の 8 項目（承認/ASK スイッチの配信経路、Agent の AI 起動構造、Windows Agent の実体とセットアップ、
  許可リストの配布、中継プロキシの置き場所、事前確認と fail-closed、監査ログ、プロジェクト前提）を
  Explore サブエージェント 3 体並列 + 自身の直接調査（SDK バンドル直読み、インストーラ・管理者権限の
  grep 確認）で洗った。
- 最重要の発見: Claude Agent SDK 0.3.282 に公式オプション `spawnClaudeCodeProcess` が存在し
  （`sdk.d.ts:2422-2441`、"Use this to run Claude Code in VMs, containers, or remote environments."）、
  SDK ホスト（Plan/Exec ゲート一式）を Agent プロセスに残したまま、実行ファイルの起動だけを別身元の
  サービスへ委譲できることを確認した。
- 推奨構成（SDK の `spawnClaudeCodeProcess` → 名前付きパイプ → NT SERVICE 仮想アカウントの Sandbox Host
  → stdio 中継。プロキシは Agent プロセス内の 127.0.0.1 CONNECT）と、段階分け SB-1（最小縦切り・
  Windows+Claude のみ）〜SB-5（範囲拡大）を Plan として提示し、人間の承認を得た。

## 検証
- 本サイクル自体はコード変更なし。SDK オプションの存在は `node_modules/.pnpm` 配下の `sdk.d.ts`/`sdk.mjs`
  を直接 grep して実装レベルで確認済み（型定義・バンドル実装の両方）。
- Windows インストーラの「管理者権限不要」設計は `install-agent.ps1` 全体 grep で `#Requires -RunAsAdministrator`
  / `sc.exe` / `New-Service` 等が不在であることを確認し、`doc/HANDOFF_WINDOWS.md:271-274` の明文化と一致。

## 発見・決定事項
- Plan/Exec ゲート（PreToolUse hook・canUseTool・disallowedTools・permissionMode・strictReadonly・
  クロス ask スコープ）はすべて in-process のクロージャ/モジュール変数であり、ファイル経由の契約が
  ゼロ。推奨構成では越境するのが `{command,args,cwd,env}` + stdio + kill + exit code の 6 項目のみに
  限定されるため、既存ゲートは 1 行も移動せず弱まらない。
- セッション resume・user scope の Capability 配布（`~/.agents/skills` 等）は仮想アカウントの HOME が
  別物になるため、Sandbox ON/OFF の切り替わり時は新規セッション化が必要（SB-1 Plan 時点の既知課題）。
- 人間の決定（2026-11-23）: 段階順は Plan どおり、スイッチはプロジェクト単位、サービスは PC 1 台に 1 つ
  全プロジェクト共用、ホストは C# ソース同梱＋インストール時ビルド、中継プロキシは Agent プロセス内、
  許可リストは Agent 設定（マシン単位、SB-1 は固定値・SB-2 で編集可）、claude ログインはトークン方式、
  git push は SB-1 では入れない、条件未達・claude 以外・端末モードは拒否、ターンごとの DB 記録は SB-1
  では持たない、管理者強制 ON は SB-4。未決のまま持ち越し: サンドボックス身元から開発者の `%APPDATA%`
  配下の claude 実行ファイル（約230MB）を読めるようにする方法（SB-1 Plan フェーズで決める）。
- 本サイクルはドキュメントのみ（`doc/sandbox/SB-0_investigation.md` 新設）。コード・設定・テストの変更
  なし。pm2 restart 不要。

詳細は `doc/sandbox/SB-0_investigation.md` を参照。
